# Dataset sources and licences

Datasets are downloaded from Roboflow Universe in YOLOv8 format. Raw data is not
included in this repository (see .gitignore); download each one from its URL.

## Used for training

### ds1: display detector (reading window)
- Name: electric-meter (workspace: wattwise, project: electric-meter-wzeeg-zk5fd), version 1
- URL: https://universe.roboflow.com/wattwise/electric-meter-wzeeg-zk5fd/dataset/1
- Licence: CC BY 4.0
- Downloaded: 25-10-2026
- Use: class "Reading" (polygon labels) converted to bounding boxes, single class "display".
  163 images in the original train/valid/test split.
- Changes made: polygons converted to bounding boxes, one image without a usable label dropped.

### ds5: digit detector (digits 0-9)
- Name: 7-seg-pro (workspace: totu), version 2
- URL: https://universe.roboflow.com/totu/7-seg-pro/dataset/2
- Licence: CC BY 4.0
- Downloaded: 25-10-2026
- Use: digit classes 0-9, merged with ds6. 819 train / 145 valid images, no original test split.

### ds6: digit detector (digits 0-9)
- Name: meter-digits (workspace: avyan), version 1
- URL: https://universe.roboflow.com/avyan/meter-digits/dataset/1
- Licence: BY-NC-SA 4.0 (attribution, NON-COMMERCIAL, share-alike)
- Downloaded: 25-10-2026
- Use: digit classes 0-9 only. The classes "-" and "." were dropped (too few examples / not in ds5).
  191 train / 54 valid / 27 test images in the original split.
- Restriction: non-commercial use only. Images are not redistributed in this repository.
  The digit model trained on ds5 + ds6 inherits this concern; see README.

### Merged digit set
ds5 and ds6 were merged by class name and re-split 70/15/15 by original photo
(src/merge_digits.py), so the final split differs from the originals.

## Downloaded but not used
- ds2, ds3, ds4: class names in data.yaml were corrupted (README text), their "Reading"
  counts matched ds1 (overlapping copies), and ds4 also contains a water-meter class.

## Own and synthetic data
- Own test photos (data/own_photos, 16 images): web or phone photos used only to test the
  reader, not for training. Source and licence of each image: <list or "own photos">.
- SYNTHETIC consumption data (data/synthetic/SYNTHETIC_*): generated by src/make_synthetic.py
  from assumed weekday and seasonal patterns. It is not real consumption data. All forecast
  results on it are labelled SYNTHETIC.
